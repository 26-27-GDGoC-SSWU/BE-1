# 💻 [BE-1] 실습 및 과제 제출 저장소

본 저장소는 스터디 실습 코드 제출 및 학습 자료 아카이빙을 위한 레포지토리입니다.

---

## 📁 디렉터리 구조

```text
├── materials/         # 주차별 세션 자료 및 정답 코드 (수정 금지)
├── week01/            # 1회차 실습 제출 폴더
├── week02/            # 2회차 실습 제출 폴더
└── ...
```

---

## 📝 파일 및 커밋 명명 규칙
제출 파일은 반드시 아래 네이밍 규칙을 지켜 해당 주차 폴더에 넣어주세요.

### 파일 명명 규칙: 멤버 이니셜_강의번호_간단요약.확장자
예시: SR_04_database.sql

### 커밋 메시지 규칙(권장): 이름 weekOO 작업내용 요약
예시: 수룡 week01 실습 파일 제출 / 수룡 week01 MySQL 04강 실습 제출 / ...

---

## 🚀 과제 제출 가이드
### 1. 저장소 복제 (최초 1회)
```bash
git clone https://github.com/26-27-GDGoC-SSWU/BE-1.git
cd BE-1
```

### 2. 최신 코드 불러오기 (과제 시작 전 필수!)
작업을 시작하기 전에 Repository의 최신 내용을 가져옵니다.

```bash
git pull origin main
```

### 3. 작업 내용 업로드
실습/과제 작성을 완료한 후 변경사항을 업로드합니다.

> 본인이 작성한 파일만 지정해서 add하는 것을 권장합니다.

```bash
git add week01/SR_04_database.sql

git commit -m "수룡 week01 실습 파일 제출"
git push origin main
```

## ⚠️ 유의사항
- materials/ 폴더 내 자료 및 다른 스터디원의 파일은 임의로 수정하거나 삭제하지 않습니다.
- DB 접속 비밀번호, 개인 API Key 등 민감한 정보는 코드에 직접 적어서 커밋하지 않도록 주의해주세요.
