# 📝 과제1 — 나만의 테이블 만들기
## ✅ 제출 내용

하나의 .sql 파일에 다음 내용을 작성해주세요.

- [ ]  CREATE TABLE — 나만의 테이블 생성
- [ ]  열(Column) 최소 3개
- [ ]  INSERT — 데이터 최소 5개
- [ ]  SELECT — 서로 다른 조회 SQL문 최소 3개
- [ ]  UPDATE — 최소 1개
- [ ]  DELETE — 최소 1개

그리고 **SQL 파일의 맨 위에 아래 내용을 주석으로 작성**해주세요.

- 테이블 명
- 테이블 설명
- 각 컬럼의 의미

```sql
-- 테이블명: movies
-- 테이블 설명: 내가 본 영화의 정보를 저장하는 테이블
--
-- 컬럼 설명
-- id : 영화의 고유 번호
-- title : 영화 제목
-- genre : 영화 장르
-- rating : 영화 평점
```
